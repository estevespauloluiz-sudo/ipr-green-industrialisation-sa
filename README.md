# Consolidated Dashboard: South Africa

Single-country interactive dashboard reconstructing South Africa's green industrialisation effort as the articulation of three levels of analysis: the international IP regime, the green financial architecture, and the domestic political economy of industrial policy.

Part of the IPR & Green Industrialisation research programme, Equal International.

**Live dashboard:** https://estevespauloluiz-sudo.github.io/ipr-green-industrialisation-sa/

## Coverage

The dashboard organises the South African case across seven navigation tabs: Overview, Value Chains (six sectors × three stages), Policies (trade, fiscal, regulatory), Targets, Financing (instruments, timeline, governance), IP Commercialisation (modality and pipeline), and References & Abbreviations.

## Running offline

All JavaScript libraries and styles are bundled in `vendor/`, so the dashboard renders without an internet connection. Because the page compiles its code in the browser, open it through a local web server (for example `python3 -m http.server`, then visit http://localhost:8000) rather than by double-clicking the file.
